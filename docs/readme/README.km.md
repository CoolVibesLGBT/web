## អំពីគម្រោង

CoolVibes ជាកម្មវិធីបណ្ដាញសង្គម មិត្តភាព និងការណាត់ជួបសម្រាប់សហគមន៍ LGBTIQA+ និងអ្នកគាំទ្រដែលគោរពសហគមន៍ អាយុចាប់ពី ១៨ ឆ្នាំឡើងទៅ។ ឃ្លាំងនេះមានចំណុចប្រទាក់វេប ការបកប្រែ រូបគំនូរ និងការធ្វើតេស្តក្នុងមូលដ្ឋាន។ API មូលដ្ឋានទិន្នន័យ និងការទូទាត់ជាសេវាដាច់ដោយឡែក។

## មុខងារ និងវិសាលភាព

ទំព័រព័ត៌មានមានការបង្ហោះ រូបថត វីដេអូ ការឆ្លើយតប ប្រតិកម្ម ចំណាំ ការស្ទង់មតិ និងព្រឹត្តិការណ៍។ ប្រវត្តិរូបមានការណែនាំខ្លួន ចំណាប់អារម្មណ៍ ចំណូលចិត្ត អ្នកតាមដាន សំណើមិត្តភាព និងរូបថតឯកជនដែលគ្រប់គ្រងដោយសិទ្ធិ។ ការស្វែងរក ការផ្គូផ្គង មនុស្សនៅជិត ផែនទី ទីកន្លែង ការចុះវត្តមាន និងការផ្សាយពាណិជ្ជកម្មជួយភ្ជាប់សហគមន៍។ ការជជែកឯកជននិងជាក្រុមគាំទ្រការឆ្លើយ បញ្ជូនបន្ត ខ្ទាស់ មេឌៀ ស្ទីកគ័រ និង GIF។ ការផ្សាយផ្ទាល់ កាបូបប្រាក់ ការណែនាំ និង Premium អាស្រ័យលើសេវានិងការកំណត់មុខងារ។

## បច្ចេកវិទ្យា និងការចាប់ផ្ដើម

កម្មវិធីប្រើ React 19, TypeScript, Vite 8 រួមជាមួយ i18next, Axios, Socket.IO, Lexical, បញ្ជីនិម្មិត, Leaflet/MapLibre និង Agora។ ត្រូវការ Yarn និង Node.js ដែលសមស្របនឹង Vite។ ពាក្យបញ្ជាខាងក្រោមជាទូទៅបើក localhost:5173។ API ក្នុងមូលដ្ឋានប្រើ 4001 ហើយ socket ប្រើ 4002/4003។

```bash
yarn install --frozen-lockfile
yarn dev

# Checks
yarn lint
yarn build
node scripts/check-documentation.mjs
```
