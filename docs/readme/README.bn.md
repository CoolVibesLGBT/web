## প্রকল্প সম্পর্কে

CoolVibes হলো ১৮ বছর বা তার বেশি বয়সী LGBTIQA+ সম্প্রদায় ও সম্মানজনক সহযোগীদের জন্য সামাজিক যোগাযোগ, বন্ধুত্ব ও ডেটিং অ্যাপ। এই সংগ্রহে ওয়েব ইন্টারফেস, অনুবাদ, চিত্র এবং স্থানীয় পরীক্ষার ব্যবস্থা রয়েছে। API, ডেটাবেস ও পেমেন্ট আলাদা পরিষেবা।

## সুবিধা ও পরিসর

ফিডে পোস্ট, ছবি, ভিডিও, উত্তর, প্রতিক্রিয়া, বুকমার্ক, জরিপ ও অনুষ্ঠান রয়েছে। প্রোফাইলে পরিচিতি, আগ্রহ, পছন্দ, অনুসারী, বন্ধুত্বের অনুরোধ এবং অনুমতিনির্ভর ব্যক্তিগত ছবি থাকে। অনুসন্ধান, ম্যাচ, কাছের মানুষ, মানচিত্র, স্থান, চেক-ইন ও বিজ্ঞাপন পরিচিতি বাড়ায়। ব্যক্তিগত ও দলীয় চ্যাটে উত্তর, ফরওয়ার্ড, পিন, মিডিয়া, স্টিকার ও GIF আছে। সরাসরি সম্প্রচার, ওয়ালেট, রেফারেল এবং Premium পরিষেবা ও ফিচার সেটিংয়ের ওপর নির্ভরশীল।

## প্রযুক্তি ও চালু করা

অ্যাপটি React 19, TypeScript ও Vite 8 ব্যবহার করে। আরও আছে i18next, Axios, Socket.IO, Lexical, ভার্চুয়াল তালিকা, Leaflet/MapLibre ও Agora। Yarn এবং Vite-সামঞ্জস্যপূর্ণ Node.js লাগবে। নিচের কমান্ড সাধারণত localhost:5173 চালু করে। স্থানীয় API হলো 4001 এবং socket হলো 4002/4003।

```bash
yarn install --frozen-lockfile
yarn dev

# Checks
yarn lint
yarn build
node scripts/check-documentation.mjs
```

## ভাষা ও ব্র্যান্ড

নেপালি ও খমেরসহ অ্যাপে ২৩টি ভাষার রূপ রয়েছে। প্রতিটি ভাষার পাতায় সংশ্লিষ্ট আঞ্চলিক মূল চিত্র থাকে। আরবি, ফারসি ও হিব্রু ডান থেকে বামে প্রদর্শিত হয়। নির্বাচিত dott-v3 পরিচয়ে CoolVibes শব্দচিহ্ন, CV আইকন এবং ফিরোজা-বেগুনি রং রয়েছে। /brandkit থেকে লোগো, আইকন, সামাজিক প্রচ্ছদ ও ZIP পাওয়া যায়।

## যাচাই ও অবদান

স্ক্রিনশটে প্রকৃত ইন্টারফেসে স্থানীয় কাল্পনিক প্রোফাইল দেখানো হয়েছে; বাস্তব অ্যাকাউন্ট বা ব্যক্তিগত বার্তা ব্যবহার করা হয়নি। ব্রাউজার পরীক্ষা প্রকৃত যন্ত্র, পেমেন্ট বা সম্প্রচারের নিশ্চয়তা নয়। নতুন অনুবাদ মাতৃভাষীদের দিয়ে পর্যালোচনা করা প্রয়োজন। মেটাডেটায় ISC আছে, তবে মূল লাইসেন্সের পাঠ নেই; পুনর্বিতরণের আগে যাচাই করুন। ইংরেজি নির্দেশিকায় পরিষেবা, স্থাপত্য ও GitBook আমদানির বিবরণ আছে।
