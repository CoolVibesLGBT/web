## על הפרויקט

CoolVibes היא אפליקציית רשת חברתית, חברות והיכרויות לקהילת LGBTIQA+ ולבעלי בריתה המכובדים, מגיל 18 ומעלה. המאגר מכיל את ממשק הרשת, התרגומים, האיורים ותרחישי הבדיקה המקומיים. ה־API, מסד הנתונים ושירותי התשלום נפרדים.

## יכולות והיקף

הפיד כולל פרסומים, תמונות, סרטונים, תגובות, סימניות, סקרים ואירועים. הפרופילים כוללים ביוגרפיה, תחומי עניין, העדפות, עוקבים, בקשות חברות ותמונות פרטיות בהרשאה. חיפוש, התאמות, אנשים בקרבת מקום, מפות, מקומות, צ׳ק־אין ומודעות מסייעים בגילוי הקהילה. שיחות פרטיות וקבוצתיות תומכות במענה, העברה, הצמדה, מדיה, מדבקות ו־GIF. שידורים חיים, ארנק, הפניות ו־Premium תלויים בשירותים ובדגלי תכונות.

## טכנולוגיה והפעלה

הממשק משתמש ב־React 19, TypeScript ו־Vite 8, לצד i18next, Axios, Socket.IO, Lexical, רשימות וירטואליות, Leaflet/MapLibre ו־Agora. נדרשים Yarn וגרסת Node.js התואמת ל־Vite. הפקודות הבאות מפעילות בדרך כלל את localhost:5173; ה־API המקומי נמצא ב־4001 וה־socket ב־4002/4003.

```bash
yarn install --frozen-lockfile
yarn dev

# Checks
yarn lint
yarn build
node scripts/check-documentation.mjs
```

## שפות ומותג

האפליקציה כוללת 23 גרסאות שפה, בהן נפאלית וחמרית. לכל דף איור אזורי מתאים. עברית, ערבית ופרסית תומכות בכתיבה מימין לשמאל. הזהות שנבחרה היא dott-v3: לוגו CoolVibes, סמל CV וגווני טורקיז וסגול. /brandkit מציע לוגואים, סמלים, תמונת שיתוף ו־ZIP.

## בדיקה ותרומה

צילומי המסך מציגים את הממשק האמיתי עם פרופילים מקומיים בדיוניים; לא נוצרו חשבונות אמיתיים ולא נחשפו הודעות פרטיות. בדיקות דפדפן אינן מאשרות מכשירים פיזיים, תשלומים או שידורים חיים. התרגומים החדשים זקוקים לבדיקת דוברי שפת אם. המטא־נתונים מציינים ISC אך אין קובץ רישיון ראשי; יש לבדוק לפני הפצה. המדריכים באנגלית מסבירים את השירותים ואת הייבוא ל־GitBook.
